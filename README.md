# LocalModAssistant
サーバーにないModをバックアップしたり入れなおしたり  
# 使い方  
1.ビーセイのインストールフォルダを指定します。  
2.Modsフォルダにzip / 7zのままMODを配置します。  
3.インストールボタンを押します。  
4.ゲームを起動するとインストールされます。  
  
アーカイブは `IPA\Pending` に展開され、次回のゲーム起動時にBSIPAがインストールフォルダへ上書きコピーします。

※アーカイブの中身の構成  
インストールフォルダ以下をそのまま再現した形で作成してください。
